## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/veltrix.git
```

### Navigate to Project Folder

```bash
cd veltrix
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```
